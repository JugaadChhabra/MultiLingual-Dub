8What I would build, in order

  1. Tokens + shell — the block at the top of this file, plus toolbar, sidebar and detail pane. Both appearances working from day one.
  2. Error classifier — a single module mapping (provider, status, body) to the catalogue above, with the honest fallback. This is backend work and the highest-value item; it is also independent of the UI, so it can ship first.
  3. Progress + notification — surface the fields JobSummary already collects, derive time remaining from started_at, wire the Notifications API and the sound.
  4. Audio section — port the dubbing pipeline into the shell using these components.
  5. Video section — port /heygen, including monitor and avatar picker.
  6. Recent jobs — the sidebar history. Last, because it is the one thing here you did not ask for, and I would rather confirm it earns its place than assume.
